  // GLOBAL KEYBOARD SHORTCUTS

  //  Ctrl+Shift+N      → New Folder      (fallback: Alt+Shift+N)

  //  Ctrl+O            → Open File       (fallback: Alt+O)
  //  Ctrl+S            → Save
  //  Ctrl+Shift+S      → Save As
  //  Ctrl+F            → Find in editor
  //  Ctrl+H            → Replace in editor
  //  Ctrl+Shift+F      → Replace in editor (alt)
  //  Ctrl+E            → Export ZIP
  //  Ctrl+G / Alt+G    → Jump to line
  //  Esc               → Close menus/modals
